# Naveed Habqook — Data Analyst Portfolio

A responsive personal portfolio website for GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation

## GitHub Pages
1. Create a GitHub repository named `portfolio` (or any name you prefer).
2. Upload these three files and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your live Pages URL.

Replace/add projects as your portfolio grows.
